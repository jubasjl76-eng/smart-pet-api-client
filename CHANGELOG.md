# Changelog

## 0.1.0 — 2026-09-10

- First release (Phase 14, A1). Generated TS client for the Smart Pet API.
  - `src/schema.d.ts` — types generated by `openapi-typescript` from
    `smart-pet-backend`'s `openapi.json` (committed; refreshed by `npm run codegen`
    and the daily `regen` workflow).
  - `createSmartPetClient({ baseUrl, token, ... })` — an `openapi-fetch` client
    with bearer auth + retry (jittered exponential backoff on 429 / 5xx / network,
    honours `Retry-After`, idempotent methods + keyed POSTs only) +
    `RateLimitedError` on exhaustion.
